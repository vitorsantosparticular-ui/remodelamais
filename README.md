# Site — Sónia A. Santos, Advogada

Site estático (HTML + CSS), sem dependências. Para ver, basta abrir `index.html` no browser.

## Por preencher
Em `index.html`, secção **Contacto**, substituir os dados entre `[ ]`:
- telefone (também no link `tel:`), email (também no `mailto:` do formulário), morada, horário
- número de WhatsApp no link `https://wa.me/351XXXXXXXXX`

## Publicar
Funciona tal como está no GitHub Pages (Settings → Pages → branch) ou no Netlify (arrastar a pasta).
